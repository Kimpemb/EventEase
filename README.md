# EventEase

Effortless Event Management, Simplified.

## Overview
EventEase is a streamlined, user-friendly platform designed to simplify event management. Whether you're an event organizer or an attendee, EventEase makes it easy to **create, join, and manage events** all in one place. Built with cutting-edge technologies like **Next.js, Firebase, and CSS**, this web application offers a seamless experience for event planning and participation.  
From intimate meetups to large-scale conferences, **EventEase** is the go-to solution for efficient and hassle-free event coordination.

## Features
- User Authentication (Signup, Login, Logout)  
- Event Creation & Management  
- Event Listing & Browsing  
- Joining Events  
- Realtime Data Handling with Firebase  
- Responsive UI with CSS  

## Tech Stack
- **Frontend:** Next.js, CSS
- **Backend:** Firebase Firestore, Firebase Auth
- **Deployment:** Vercel (Frontend), Firebase (Database & Authentication)

## Installation & Usage
### Local Setup
1. Clone the repository:
```bash
   git clone https://github.com/Kimpemb/EventEase.git
```
2. Navigate to the project directory:
```bash
   cd EventEase
```
3. Install dependencies:
```bash
   npm install
```
4. Create a `.env.local` file and add your Firebase credentials:
```
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```
5. Run the application:
```bash
   npm run dev
```
6. Visit the app at `http://localhost:3000`
